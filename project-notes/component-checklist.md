# 컴포넌트 점검 기준

상태: 아직 전체 검증 전. 아래 항목은 점검할 기준이며 통과 결과가 아니다.

## 1. 개발 환경과 목록

- [ ] 패키지 설정·스타일 변수·프리셋 등 필수 파일의 누락 상태 확인
- [ ] 설치된 의존성으로 빌드·타입 검사·기존 테스트 실행
- [ ] 기본 컴포넌트·하위 구성 요소·Block·Kit를 구분한 목록 작성
- [ ] 실제 파일, 공개 export, CLI 설치 목록, 문서 예제 대응 확인
- [ ] Vue 기존 구현과 React의 주요 기능 차이 기록

## 2. KRDS 반영

- [ ] 점검 기준으로 사용할 KRDS 버전과 공식 항목 출처 기록
- [ ] 색상·타이포그래피·간격·크기 등 토큰 적용 확인
- [ ] 기본·초점·비활성·오류 등 컴포넌트별 상태 확인
- [ ] 반응형·긴 한국어 콘텐츠·확대 시 레이아웃 확인
- [ ] 공통 토큰 변경이 컴포넌트와 실제 화면에 반영되는지 확인

## 3. 웹접근성

- [ ] 시맨틱 요소, 접근 가능한 이름, 레이블 연결 확인
- [ ] 키보드 조작, 초점 표시·순서 확인
- [ ] 모달·메뉴 등에서 열기·닫기·초점 복귀 확인
- [ ] 오류 안내와 상태 변화가 보조기기에 전달되는지 확인
- [ ] 대비, 확대, 스크린리더 동작 확인
- [ ] 자동 검사와 수동 확인 결과를 분리해 기록

## 4. 납품 프로젝트에서의 사용성

- [ ] Vue props·events·v-model 사용 규칙의 일관성 확인
- [ ] 폼 검증, 로딩·빈 화면·오류 상태 예제 확인
- [ ] API 연동 예제와 컴포넌트의 책임 구분 확인
- [ ] 새 참여자가 설치부터 예제 화면 구현까지 따라 할 수 있는지 확인
- [ ] CMS 화면에서 조합했을 때 기능과 접근성 재검증

## 결과 기록 형식

개별 점검표에는 `컴포넌트 / 기준·출처 / 결과(통과·실패·미확인·해당 없음) / 근거 / 다음 조치`를 기록한다. 파일 수나 테스트 존재만으로 품질을 판정하지 않는다.
