# hanui-workspace

HANUI 공공기관 CMS 작업 공간입니다.

이 저장소는 여러 독립 Git 저장소를 함께 작업하기 위한 상위 문서 저장소입니다.

## 하위 저장소

| 폴더 | 역할 | 관리 방식 |
| --- | --- | --- |
| `hanui/` | HANUI React·Vue 컴포넌트와 CLI | 별도 Git 저장소 |
| `hanui-cms/` | 공개 홈페이지·관리자·백엔드 | 별도 Git 저장소 |
| `krds-checker/` | KRDS·접근성 점검 도구 | 별도 Git 저장소 |
| `claude-settings/` | 개발 설정과 훅 | 별도 Git 저장소 |
| `project-notes/` | 사업·기술·검증 기록 | 이 저장소에서 관리 |
| `reference/` | 외부 기준 소스와 기준 커밋 | 이 저장소에서 관리 |

자식 저장소의 코드 변경은 각 저장소에서 별도로 commit·push합니다. 이 저장소에는 작업 인계 문서, 결정 기록, 검증 기록, 외부 기준의 버전 정보만 저장합니다.

작업을 이어갈 때는 먼저 [HANDOFF.md](HANDOFF.md)를 읽습니다.
