## 폴더 구조

```
edudata-contest/
├── docs/
│   ├── plan.md          # 작전 (~/.claude/plans/ 동기화)
│   ├── contest-info.md  # 대회 정보 (요강 정리)
│   ├── concept.md       # 컨셉 회전 히스토리 (132건 분석·1차/2차 폐기 사유·B 방향)
│   └── ideas.md         # 아이디어 풀 (1·2·3차 발산 + 통합 후보)
├── data/                # 다운받은 공공데이터 (CSV/JSON)
├── notebooks/           # 데이터 탐색 (.ipynb 또는 .py)
└── app/                 # Next.js 프로젝트 (컨셉 확정 후 init)
```

## 다음 단계

1. 컨셉 1개 확정 (docs/ideas.md 후보 중)
