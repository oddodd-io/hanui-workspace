## 1차 컨셉 (폐기, 2026-05-18)

**"학교지도(EduMap) — 이사·전학 학부모를 위한 학교 데이터 탐색기"**

- 페르소나: 신정동 → 광명 이사 가는 학부모
- 본인 동기: 아들이 학폭 많은 학교(상동고)인 줄 모르고 전학
- 5+1 기능: 학구도 / 학폭 / 성취도 / 학급규모 / 학원 인프라 / AI 매칭

### 폐기 사유 (1차)

132건 수상작 캡쳐 분석 + 사용자 직관:

1. **빈익빈 부익부 우려**: "이 학교 학폭 많아, 가지마" = 학군 격차 강화 = 교육부 미션 정반대 (교육부 = 격차 해소 / 사각지대 / 소외 지원)
2. **수상작 키워드 정렬 X**: 대상·최우수상은 "격차 해소 / 사각지대 / 맞춤형 지원 / AI+사회적 약자" 패턴
3. **선행 작품 직격**: 제6회 일반부 최우수상 "AI기반 학교폭력 통합지원 시스템(Tech-Nova)"과 키워드 충돌
4. **활용가능성 X**: 학교 비교 = 일회성. 매일 쓸 도구 아님

## 2차 컨셉 (폐기, 2026-05-18)

**"우리아이 학교 — 사교육 컨설팅 없이도, 정보 격차 없는 학교 선택"** (1차 회전)

5+1 기능 재조정:
1. 학구도 (정보 평등화)
2. 학교 안전망 (Wee클래스·상담실)
3. 학습 지원 프로그램 (기초학력·다문화·특수교육)
4. 학급당 학생수/교사 수
5. 공공 학습 자원 (도서관·청소년수련관·늘봄)
+. AI 적합도 매칭 (랭킹 X)

### 폐기 사유 (2차)

사용자 추가 통찰:

- 초등학교: 거주지 자동 배정 → 학교 선택 불가
- 중학교: 거의 자동 배정
- 고등학교만 일부 선택 가능 (특목·자사·평준화 추첨)

→ **"학교 선택 도구"의 전제 자체가 무너짐.** 본인 자녀도 둘 다 자동 배정·이미 결정 상태. 페르소나 페인 약함.

## 현재 검토 컨셉 (B 방향, 2026-05-19)

**"데이터로 보는 진로 — 학과·등급·진로의 진짜 숫자"**

### 세 요소 묶음

1. **학과 → 졸업 후 진로 실제 분포**
   - 데이터: 한국교육고용패널(KEEP) + 대학알리미 + 워크넷
   - "사회복지학과 가면 다 사회복지사? 30%다. 나머지는 어디로?"

2. **내 등급 → 진학한 학생들의 분포**
   - 데이터: 대학어디가 + 대학알리미
   - "같은 등급, 다른 결과" 시각화

3. **AI 자연어 매칭**
   - Claude API
   - "고1 우리 아들 영어 좋아함, 사교육 안 가능 → 데이터 근거 답변"

### 본인 스토리 (익명화 — 제출물에 지역명·학교명·회사명 금지)

> *"두 아이 키우는 일하는 엄마. 아들 고1, 사교육비 부담은 현실. 입시 컨설팅 100만원 받을 형편도 시간도 없는데 카더라뿐이었다. 20년 개발한 손으로 직접 만들었다 — 데이터로."*

### 강점

- **운영진 예시 정렬**: 운영 안내 PDF에 "AI 진로·직업 탐색 지원 서비스 기획" 명시
- **활용가능성 1순위 정렬**: 고1·고2·고3 학부모 + 학생 = 매일 쓰는 도구
- **본인 페인 직격**: 아들 진로 결정 + 사교육비 부담
- **빈익빈 회피**: "학교 선택" X, "우리 아이 개별 시뮬레이션" O
- **본인 강점 활용**: 시간축 시각화·인터랙티브·UI/UX
- **데이터 풍부**: KEEP(종단)·대학알리미·NEIS·워크넷

### 리스크

- 진로 작품 다수 수상 이력 → 각도 차별화 필수
  - vs KNN 학점제: 우리는 학과→직업 진짜 데이터
  - vs K-12 커리어 네비게이터: 우리는 학부모-학생 동반 + 비용 시뮬레이션
  - vs 희망 진로 강좌 추천: 우리는 데이터 시각화 도구

### 현실 목표

- **장려상~우수상권**: 충분히 가능
- **최우수상**: 잘 만들면 가능
- **대상**: 어려움 (대상 패턴 = AI+사회적 약자 또는 정책+ML)
- **대상 시 부상**: 범정부 공공데이터 AI 활용대회 통합본선 진출 추천
