# v1 로드맵 — 그누보드 기준 차수 계획

작성일: 2026-10-01
상태: **사용자 확정** (→ [기술 선택](decisions.md) 2026-10-01 · v1 범위와 차수)

## 1. v1의 정의

**v1 = 그누보드(5) 수준의 소규모 공공기관 홈페이지 CMS.**

그누보드는 소규모 기관·학교·단체 홈페이지에서 널리 쓰여 담당자에게 익숙하다. v1은 그누보드의 기능·화면 배치를 **레퍼런스**로 삼되, 공공기관 홈페이지에 맞지 않는 커뮤니티·쇼핑 기능은 넣지 않는다. 화면은 KRDS(`@hanui/vue`)로 만들고, 웹접근성·KRDS 기준은 [첫 납품 범위](first-delivery.md)의 출고 기준을 따른다.

- 기능을 그대로 복제하지 않는다. 그누보드의 구조(게시판 중심, 관리자 왼쪽 분류 메뉴, 최신글 등)를 참고한다.
- 그누보드 정보는 공개된 일반 구성 기준이다. 상세 화면을 옮길 때는 해당 버전 자료를 다시 확인한다.

## 2. 그누보드 기능 분류

| 분류 | 그누보드 기능 | v1 판단 | 차수 |
| --- | --- | --- | --- |
| 게시판 | 게시판 생성·설정, 분류, 목록·검색·상세·글쓰기, 첨부, 최신글 | 핵심 | 1차 |
| 게시판 확장 | 공지 상단고정 | 포함 | 1차 |
| 게시판 확장 | 게시판 그룹, 게시판별 권한 세분화 | 포함 | 2차 |
| 게시판 확장 | 댓글, 비밀글, 답변글 | 포함 | 3차 |
| 콘텐츠 | 내용관리(고정 페이지) | 포함 | 1차 |
| 콘텐츠 | FAQ, 팝업레이어 | 포함 | 2차 |
| 사이트 | 기본환경설정, 메뉴설정, 사이트맵 | 포함 | 1차 |
| 사이트 | 통합검색, 새글 모아보기 | 포함 | 2차 |
| 문의 | 1:1문의 | 포함 — **비회원 문의 + 비밀번호** | 3차 |
| 운영 | 관리자 계정·역할(관리자·담당자), 변경 기록 | 포함 | 1차 |
| 운영 | 관리권한설정 세분화, 접속자 집계·글 현황 | 포함 | 2차 |
| 회원 | 공개 회원가입·로그인·마이페이지, 회원관리, 회원 메일 발송 | **v1 제외** — 필요한 기관이 생기면 추가 | — |
| 참여 | 설문(투표) | 선택 | 3차(선택) |
| 커뮤니티 | 포인트, 쪽지, 스크랩, 현재접속자 | 제외 | — |
| 기타 | 쇼핑몰(영카트), SMS, 테마 마켓, 캐시·세션 관리 화면 | 제외 | — |

**회원 기능을 v1에서 빼는 이유**: 개인정보 수집 동의, 보관·파기, 비밀번호 정책, 본인확인 등 법적 요구가 함께 들어와 범위가 크게 늘어난다. 소규모 기관 홈페이지는 회원 없이 운영하는 경우가 많다. 방문자 참여는 3차의 비회원 1:1문의로 처리한다.

## 3. 차수

### 1차 — 운영 가능한 최소 홈페이지

첫 납품 범위(F01~F13)와 기존 Phase 1-A에 대응한다.

| 영역 | 내용 |
| --- | --- |
| 관리자 기본 | 로그인·로그아웃·세션 만료·비밀번호 변경, 계정 2역할(관리자·담당자), 대시보드(최근 글) |
| 관리자 레이아웃 | 그누보드식 배치 — 상단 바 + 왼쪽 분류 메뉴(게시판관리 / 내용관리 / 메뉴관리 / 환경설정 / 계정관리) |
| 게시판 관리 | 게시판 생성·설정(이름, 주소, 목록 수, 분류) |
| 게시글 | 작성·수정·첨부·초안·게시·게시 중단·휴지통·복원, 공지 상단고정, 제한된 편집기 |
| 콘텐츠·사이트 | 내용관리(고정 페이지), 메뉴설정, 기본환경설정(기관 정보·로고·푸터) |
| 공개 사이트 | 공통 레이아웃, 게시판 목록·검색·상세, 홈 최신글, 고정 페이지, 사이트맵, 오류 화면 |
| 운영 | 변경 기록, 설치·백업·복구 문서 |

**첫 납품 범위와 달라진 점**: F04는 공지·자료실 고정 게시판이었으나, 1차는 **관리자가 게시판을 만들고 분류를 설정**하는 그누보드 방식으로 넓힌다. 공지 상단고정은 기존 Phase 1-B에서 1차로 당긴다.

**완료 기준**: [첫 납품 범위](first-delivery.md)의 내부 출고 기준 G01~G07과 시나리오를 그대로 쓴다.

### 2차 — 부가 콘텐츠·운영 기능

| 영역 | 내용 |
| --- | --- |
| 콘텐츠 | FAQ, 팝업레이어 |
| 탐색 | 통합검색, 새글 모아보기 |
| 게시판 | 게시판 그룹, 게시판별 권한 세분화(관리권한설정) |
| 게시 | 예약발행, 분할 미리보기 (기존 Phase 1-B) |
| 운영 | 접속자 집계·글 현황(대시보드 통계) |

**완료 기준**: 1차 기준 유지 + 2차 시작 전에 추가 기준을 정한다(예: 팝업레이어 접근성 — 초점 이동·닫기·"오늘 하루 보지 않기" 동작, 예약발행 시각 정확성).

### 3차 — 방문자 참여 기능

개인정보 처리가 따라오므로 마지막에 둔다.

| 영역 | 내용 |
| --- | --- |
| 문의 | 1:1문의 — 비회원 문의(이름·연락처·비밀번호) + 담당자 답변, 개인정보 수집 동의·보관 기간·파기 |
| 게시판 | 댓글, 비밀글, 답변글 |
| 참여 (선택) | 설문(투표) |

**완료 기준**: 1·2차 기준 유지 + 3차 시작 전에 개인정보 처리 기준(수집 항목·동의 문구·보관·파기·열람 권한)을 정한다.

### v1 이후

기존 계획의 Phase 2~5: 접근성 자동 검사, HWP/PDF 뷰어, 인라인 편집, 성과보고서, AI 글쓰기, 긴급공지 모드, 게시글 템플릿, 승인 워크플로, 회원 기능(필요 시).
