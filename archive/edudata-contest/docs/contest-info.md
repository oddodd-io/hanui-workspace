## ⚠️ 일반부 평가 기준 (절대 외울 것)

**1차 심사 (서면) 우선순위**: 
**활용가능성 → AI 활용도 → 독창성 → 논리성 → 표현성**

→ **활용가능성이 1순위**. "누가 매일 쓸 도구인가"가 정면 평가됨. 빈익빈 부익부 도구 = 활용가능성 의심 = 1차 탈락.

**2차 심사 (발표) 우선순위**: 
**합리성 → 이해도 → 창의성 → 발표·태도**

→ 합리성 1위 = 데이터 + 논리 + 명분 일관성.

**시상 편수의 2배수 1차 통과 → 동점자는 우선순위 높은 작품 선정** = 활용가능성 점수가 사실상 운명을 가름.
