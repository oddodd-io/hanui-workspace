## 기록 방법

- 작업 재개 시 사업 목적, 최근 기술 선택, 할 일을 먼저 읽는다.
- 사용자가 설명한 현장 경험, 코드로 확인한 사실, 제안, 확정 결정을 구분한다.
- 중요한 방향이 바뀌면 기술 선택 기록에 날짜와 이유를 남긴다. 구현 상태는 할 일 문서에 반영한다.
- 완료한 일은 체크하고 검증 결과나 관련 파일을 기록한다. 실행하지 못한 검사는 미확인으로 남긴다.
- 체크리스트는 반복 사용하는 기준이다. 개별 컴포넌트의 결과는 별도 점검표에 기록한다.
- 같은 내용을 여러 문서에 복제하기보다 해당 문서로 연결한다.

이 폴더는 상위 로컬 작업 공간에 있으며 현재 Git 저장소에 포함되지 않는다. 별도 저장소 생성이나 원격 공개는 하지 않았다.
