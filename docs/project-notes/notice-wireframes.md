# 공지 화면 와이어프레임과 입력 항목

2026-09-21 · 설계 초안. 실제 CMS 구현·접근성 검증은 별도다.
기준: [사이트맵·권한](sitemap-and-permissions.md), [Vue 점검 결과](vue-audit.md).

## 1. 관리자 공지 목록 (M03)

```text
[관리자 메뉴]   공지사항                         [공지 작성]
               게시 상태 [전체 ▼]  제목 [             ] [검색]
               총 24건
               제목                  상태          수정일       수정자
               2026 사업 안내        게시 중       2026-09-21   담당자
               운영시간 변경         초안          2026-09-21   담당자
               < 이전   1  2  3   다음 >
```

- 목록 열: 제목(편집 링크), 상태, 미게시 변경 유무, 수정일, 수정자. 첫 버전은 일괄 선택·삭제를 넣지 않는다.
- 필터·검색·현재 페이지를 URL에 유지한다. 검색 적용 시 첫 페이지로 이동한다.
- 로딩 중 기존 결과를 지우지 않고 상태를 알린다. 최초 로딩·빈 목록·검색 결과 없음·요청 실패를 구분한다.
- 모바일은 제목과 상태를 우선 배치하되 수정 정보도 읽을 수 있도록 줄바꿈한다.

## 2. 관리자 공지 작성·수정 (M04)

```text
공지사항 > 공지 작성                        초안 · 저장 전 변경 있음
제목 *    [                                                       ]
본문 *
[제목 수준] [굵게] [목록] [링크] [이미지] [표]
┌────────────────────────────────────────────────────────────────┐
│ 본문 작성 영역                                                  │
└────────────────────────────────────────────────────────────────┘
첨부파일   [파일 선택]   PDF/HWP 등 · 파일당 최대 20MB (제안)
           사업안내.pdf  240KB  업로드 완료  [제거]
게시 전 확인
  이미지 설명, 표 머리글, 링크 설명 등 확인 결과
[목록으로]                         [초안 저장] [미리보기] [게시]
```

| 항목 | 입력·검증 제안 | 오류 표시 |
| --- | --- | --- |
| 게시판 | 목록에서 선택한 공지사항으로 고정 | 존재·권한 서버 확인 |
| 제목 | 필수, 공백만 불가, 최대 200자 | 제목 바로 아래 설명, 오류 요약에서 초점 이동 |
| 본문 | 필수. 구조화 문서로 저장, 허용 블록·마크만 수용 | 비어 있음·허용하지 않은 구조 구분 |
| 이미지 | 업로드 완료 후 삽입. 정보 이미지 설명 필수, 장식 여부 명시 | 해당 이미지 편집 위치로 이동 |
| 표 | 단순 표만, 표 목적·머리글 지정 지원 | 누락 위치와 수정 방법 제공 |
| 링크 | 표시 문구·허용 URL 확인, 새 창 선택 시 안내 | 링크 편집 위치로 이동 |
| 첨부 | 허용 유형·20MB 제한은 서버에서도 확인 | 실패 파일별 재시도·제거, 성공 파일은 유지 |
| 내부 버전 | 현재 버전과 서버 버전 대조 | 충돌 시 덮어쓰기 금지, 새 버전 열기와 입력 보존 제공 |

이미지·파일 관련 제한은 [첫 납품 범위](first-delivery.md)의 제안값이며 실제 기관 정책으로 확정한다.

### 저장·미리보기·게시

- 초안 저장은 작성 중 내용을 저장한다. 게시 필수 조건이 미완성이어도 위험한 문서 구조·파일은 서버에서 거부한다.
- 미리보기는 저장된 초안을 표시한다. 변경이 있으면 저장 후 열며 저장 실패 시 열지 않는다. 새 창을 쓰면 버튼에 이를 알린다.
- 게시 버튼은 클라이언트·서버 검증 후 공개 리비전을 교체한다. 처리 중 재요청을 막고 성공 여부를 알린다.
- 수정 초안 저장만으로 공개 글이 바뀌지 않는다. 화면에 ‘현재 공개본과 다른 변경이 있습니다’를 표시한다.
- 실패 시 제목·본문을 지우지 않는다. 서버 성공 여부가 불확실하면 상태를 조회한 뒤 재시도를 안내한다.
- 페이지를 떠날 때 미저장 변경을 확인한다. 세션 만료 후 입력 복원 범위는 인증·민감정보 정책과 함께 설계한다.

## 3. 공개 공지 목록 (P05)

```text
기관 공통 헤더·메뉴
홈 > 알림·자료 > 공지사항
공지사항
제목 [                                      ] [검색]
총 24건
번호   제목                                     등록일
24     2026 사업 안내                            2026-09-21
23     운영시간 변경 안내                        2026-09-20
< 이전   1  2  3   다음 >
기관 공통 푸터
```

목록 제목 링크는 전체 제목을 접근 가능한 이름으로 제공한다. 파일 첨부 표시는 아이콘만으로 전달하지 않는다. 공개 목록은 게시본만 사용하고 관리자 수정일 대신 공개용 게시일을 표시한다.

## 4. 공개 공지 상세 (P06)

```text
홈 > 알림·자료 > 공지사항
2026 사업 안내
등록일 2026-09-21
──────────────────────────────────────────────────────────────
본문: 제목·문단·목록·이미지·표
──────────────────────────────────────────────────────────────
첨부파일
[사업안내.pdf 다운로드]  PDF · 240KB
[목록으로]
```

본문은 관리자와 동일한 문서 구조를 사용하되 공개 리비전만 렌더링한다. 본문 제목은 페이지 제목 아래의 계층을 유지한다. 첨부 링크는 파일명·형식·용량을 제공하고, 목록 복귀 시 검색 조건을 유지한다.

## 5. 필요한 Vue 기반과 남은 위험

| 화면 요소 | 우선 사용할 기존 요소 | 적용 전 확인 |
| --- | --- | --- |
| 동작·검색·제목 | Button, Input, Select | 외부 label·오류 메시지 연결, 브라우저 키보드 조작 |
| 목록 | Table, TableHead, Pagination | caption·열 머리글, 검색 결과 안내, 실제 모바일 배치 |
| 상태·오류 | Badge, Alert | 상태를 색상만으로 전달하지 않기 |
| 게시 확인·이탈 확인 | Modal | 외부 영역 비활성 처리·스크린리더 확인 |
| 레이아웃 | Header, Breadcrumb, Footer, SkipLink | 전체 페이지 탐색·반응형·초점 순서 |
| 본문·첨부 | 편집기 연결, FileUpload | 편집기 접근성, 안전한 저장·렌더링, 파일 서버 권한 |

현재 Vue 컴포넌트 테스트 통과는 전체 화면 KRDS·접근성 합격이 아니다. 스타일 토큰·Tailwind 제공 경로부터 정리한 뒤 브라우저에서 조합 화면을 검증한다.

## 6. 다음 구현 단위

공지 한 건의 초안 저장 → 권한 있는 미리보기 → 게시 → 공개 목록·상세를 먼저 연결한다. API·데이터 모델에는 콘텐츠 ID, 게시판, 편집 리비전, 공개 리비전, 버전, 첨부 참조, 생성·수정·게시 이력을 명시한다. 서버 v5 설정과 인증 방식을 확정한 뒤 실제 계약을 작성한다.
