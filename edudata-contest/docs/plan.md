# 데이터 가용성 검증 절차 (B + C)

## Context

제8회 교육 공공데이터 AI 활용대회 일반부 출품을 위한 사전 작업. **2026-05-31 23:59 마감, 오늘 2026-05-18 기준 13일 남음.**

사용자는 광명 이사 + 두 자녀 전학 당사자.

**⚠️ 컨셉 회전 (2026-05-18, 132건 수상작 패턴 분석 후)**

기존: "학교지도(EduMap) — 이사·전학 학부모를 위한 학교 데이터 탐색기"
→ 위험 진단: "좋은 학교 찾기" = 학군 격차 강화 도구 = 교육부 미션 정반대 (격차 해소 / 사각지대 / 소외 / 맞춤형 지원). 또한 "AI기반 학교폭력 통합지원 시스템" (제6회 일반부 최우수상)과 키워드 직격.

신규: **"우리아이 학교 — 사교육 컨설팅 없이도, 정보 격차 없는 학교 선택"**

명분 정렬: 사교육 컨설팅 = 학부모 정보 비대칭. 잘 사는 동네 학부모는 100만원 컨설팅으로 정보 입수. 우리는 공공데이터로 모든 학부모에게 무료 평등 제공. **"정보 격차 = 교육 격차의 시작"** = 교육부 가치 100% 정렬.

본인 동기 스토리도 회전: "아들이 학폭 많은 학교인 줄 모르고 전학" → "사교육 컨설팅 받을 여유는 없는데 학교 정보는 카더라뿐이었다."

**확정 5기능 (정치적 안전 재조정)**:
1. **학구도** (아파트 → 학교 배정) — 정보 평등화 본질
2. **학교 안전망 / Wee클래스 / 상담실 운영** (학폭 발생률 직접 노출 X, "사후 지원 인프라" 강조)
3. **학습 지원 프로그램 / 기초학력 보장 사업 / 다문화·특수교육 지원** (성취도 직접 노출 X, "격차 해소 데이터" 강조)
4. **학급당 학생수 / 교사 수** — 교육 환경 격차 데이터
5. **공공 학습 자원** (학교 도서관 + 지역 공공도서관 + 늘봄·돌봄 + 청소년수련관 + 방과후) — 사교육 학원 대체 정보 (학원 인프라 컷)
6. **AI 자연어 매칭** (가산): "초5 영어 좋아하는 우리 딸한테 어떤 학교 프로그램?" → Claude API + 데이터 근거. **랭킹 X, 적합도 매칭 O** (빈익빈 부익부 회피의 핵심 UX 패턴)

본 plan은 위 5+1기능이 **실제 공공데이터로 구현 가능한지 사전 검증하는 절차**다.

## 핵심 의사결정 — 지도 처리 방식

학구도 + 학원 히트맵 = 5기능 중 2개가 지도 기반. visx-geo로 직접 구현 vs 검증된 지도 SDK 사용 선택 필요.

### 옵션 A: visx-geo + react-simple-maps + 한국 행정구역 GeoJSON
- 장점: "HANUI Visx 풀스택 시각화" 포폴 강도 최대
- 단점: 학구도 폴리곤 데이터 직접 가공, 좌표계 변환, 줌/인터랙션 처음부터. 1주일 잡아먹을 위험.

### 옵션 B (추천): Kakao 지도 SDK + Visx는 차트만
- 학구도 폴리곤은 Kakao 지도 위에 GeoJSON 오버레이
- 학원 히트맵은 Kakao 지도 클러스터러 + 커스텀 색상
- Visx는 학교폭력/성취도/학급규모 비교 차트에만 집중
- 시간 절감 1주일+, 한국 사용자 친숙도 최고, 사용자가 어차피 Visx만으로 평가받는 게 아님

### 옵션 C: Mapbox GL JS + 한국 GeoJSON
- 시각화 자유도 최고, 영문 심사위원 시연 시 인터내셔널 인상
- 단점: 무료 한도 + 영문 위주, 한국 학구도 데이터 합치는 작업은 동일

→ **추천: 옵션 B**. 13일 + 1인 + 본업/이사 동시진행 제약에서 가장 합리적. 심사 평가는 출품작 완성도, "Visx로 다 만들었는가"가 아님.
