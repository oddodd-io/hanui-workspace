# 1차 수동 확인 (2026-10-02)

1차 독립 검토 OK 이후 남은 사람 확인 항목. 사용자가 직접 확인하고 결과를 아래 "결과" 칸에 적는다(또는 Claude에게 알려 주면 기록·수정).
자동 테스트로는 볼 수 없는 것만 모았다. 관련 기록: [tasks.md](../tasks.md) "1차 독립 검토 OK".

## 준비 (집 등 다른 컴퓨터에서)

```bash
# 세 저장소 모두 최신으로
cd hanui-workspace && git pull
git -C repos/hanui pull
git -C repos/hanui-vue-cms pull

# 1) 라이브러리 빌드 — CMS가 repos/hanui/packages/vue/dist를 link로 쓴다 (dist는 저장소에 없음)
cd repos/hanui && pnpm install && pnpm --filter @hanui/vue build

# 2) CMS 의존성
cd ../hanui-vue-cms && pnpm install

# 3) 터미널 3개에서 각각
pnpm mock         # mock API  http://localhost:4010
pnpm dev:admin    # 관리자    http://localhost:3400
pnpm dev:public   # 공개      http://localhost:3300
```

- 3000번은 쓰지 않는다(다른 프로젝트).
- 계정: `admin` / `admin1234!` (관리자), `editor` / `editor1234!` (담당자)
- mock은 메모리 저장이라 껐다 켜면 처음 데이터로 돌아간다.

결과 적는 법: `통과` 또는 `어느 화면 / 무엇을 했더니 / 어떻게 됐다`

## 1. 한글 입력기 (가장 먼저)

텍스트 수정·미리보기 편집은 입력할 때마다 HTML을 맞추는 방식이라, 한글 조합 중인 글자에서 문제가 생길 수 있다.

| # | 화면 / 할 일 | 볼 것 | 결과 |
| --- | --- | --- | --- |
| 1-1 | 페이지 편집(내용관리 → 페이지 하나) → **텍스트 수정** 탭에서 문단 중간에 "안녕하세요 반갑습니다" 입력 | 글자 깨짐, 자음·모음 분리, 커서 튐, 글자 중복 없음 | |
| 1-2 | 같은 화면 **HTML 소스** 탭 → 오른쪽 미리보기에서 한글 입력 | 1-1과 같음 + 왼쪽 소스에 바로 반영 | |
| 1-3 | 1-2 입력 직후 소스 쪽에서 한글 입력 → 다시 미리보기에서 입력 | 둘 다 보존(덮어쓰기 없음) | |
| 1-4 | **간편 편집** 탭에서 한글 입력, 목록·표 안에서도 | 같음 | |
| 1-5 | **HTML 소스** 편집기(코드 칸)에서 한글 입력 | 같음 | |
| 1-6 | 게시글 쓰기 제목 칸, 메뉴설정 메뉴 이름 칸 | 같음 | |
| 1-7 | 입력 중 Enter·Backspace(조합 중일 때 포함) | 줄이 이상하게 나뉘거나 구조가 깨지지 않음 | |

## 2. 화면낭독기 (Mac VoiceOver: Cmd+F5)

| # | 화면 / 할 일 | 볼 것 | 결과 |

| 2-10 | 휴지통: 복원 실패 상황 | 안내로 초점 이동 | |
| 2-11 | 첨부 파일 오류(허용 안 되는 파일) | 오류 낭독. (알려진 문제: 업로드 버튼과 describedby 연결 없음) | |
| 2-12 | 공개 사이트 게시글 상세·고정 페이지 | 제목 구조, 표 머리글, 첨부 목록 낭독 | |
